# IT Conference API

Учебный бэкенд-проект для лендинга IT-конференции. Лабораторная работа №8: разработка REST API на Node.js/Express.js с подключением к MongoDB.

## Стек

- **Node.js** (среда выполнения)
- **Express.js** (веб-фреймворк)
- **MongoDB** (база данных)
- **Mongoose** (ODM для MongoDB)
- **dotenv** (для переменных окружения)
- **cors** (для кросс-доменных запросов)
- **nodemon** (для разработки)

## Требования

- Node.js **18+**
- MongoDB (локально через Docker или облако MongoDB Atlas)
